# AICT 연습 (SK AI 실무역량검사 대비)

SK AI 실무역량검사(AICT)를 맥북에서 실전처럼 연습하는 로컬 웹앱입니다.
화면 속 AI 채팅만으로 과제를 풀고 답안을 제출하면, AI가 루브릭에 따라 채점하고 피드백을 줍니다.

## 실행

```bash
cd ~/workspace/aict
npm install      # 처음 한 번만
npm run dev
```

브라우저에서 http://localhost:3000 을 열고, 시험 중에는 전체화면(⌃⌘F)으로 쓰는 것을 권장합니다.
종료는 터미널에서 `Ctrl+C`를 누릅니다.

## AI 연결

기본값은 이 맥에 설치된 **Claude Code CLI**(`claude`)이므로 API 키 없이 바로 쓸 수 있습니다.

`설정` 화면에서 다음을 바꿀 수 있습니다.

- **AI 채팅 모델**: 시험 중 AI Agent 역할을 하는 모델. 시험 화면의 채팅 헤더에서도 바로 바꿀 수 있습니다.
- **채점·문제 생성 모델**: 채팅 모델과 따로 지정합니다. 성능이 높은 모델을 권장합니다.
- **API 키**: Claude API, OpenAI(ChatGPT), Google Gemini. 키는 `data/settings.json`에만 저장됩니다.
  환경변수 `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`도 인식합니다.

CLI 모델은 `sonnet`, `opus`, `haiku` 같은 별칭이나 전체 모델명으로 지정합니다.
API 공급자는 `모델 목록 불러오기`로 지금 쓸 수 있는 모델을 조회할 수 있습니다.

## 연습 모드

| 모드 | 내용 |
|---|---|
| 모의고사 (Global) | 60분(스피드 모드 30분). Stage 1 비즈니스 솔루션 설계 + Stage 2 전략적 커뮤니케이션을 문제 은행에서 무작위로 출제 |

| AI 문제 생성 | 유형·산업·추가 조건을 지정하면 실제 시험 형식의 새 문제를 생성. 문제 은행에 저장 가능 |

## 시험 화면

- 3분할 화면: 문제 | 답안 에디터 | AI 채팅. `에디터 가운데`(SK AX 버전)와 `채팅 가운데`(SK C&C 버전) 배치 중에서 고를 수 있고, 패널 경계를 드래그해 폭을 조절합니다.
- AI는 문제 내용을 모릅니다. 실제 시험처럼 필요한 맥락은 직접 전달해야 합니다. 채팅 입력은 4,000자까지입니다.
- 답안 에디터에는 서식 툴바(표, 목록, 정렬 등)와 글자수 표시가 있고, 변경하면 자동저장됩니다.
- **답안지 제출** 후에는 그 문제를 수정할 수 없고, 다음 문제를 푸는 동안 백그라운드에서 채점이 진행됩니다.
- 제한시간이 끝나면 자동 제출됩니다. 다른 창이나 탭으로 이동하면 화면 이탈로 기록됩니다.

## 채점 (100점)

| 항목 | 배점 |
|---|---|
| 요구사항 충족도 | 30 |
| 논리·구조 | 20 |
| 구체성·실행가능성 | 20 |
| 독자·톤·커뮤니케이션 | 15 |
| AI 활용 역량 (프롬프트 구체성, 반복 개선, 검증, 복붙 여부) | 15 |

결과 화면에서는 항목별 근거, 잘한 점과 개선점, **더 나은 프롬프트 예시**, **모범 답안**, 채팅 로그를 볼 수 있습니다.
AI 채점이라 같은 답안도 점수가 몇 점씩 달라질 수 있습니다. `다시 채점`으로 재채점할 수 있습니다.

## 구조

```
app/                 페이지(홈·시험·결과·기록·설정·문제 생성)와 API 라우트
components/          시험 화면 컴포넌트 (ChatPanel, AnswerEditor, ProblemPanel)
lib/llm/             AI 공급자 연동 (Claude CLI, Anthropic, OpenAI, Gemini)
lib/prompts.ts       채팅 시스템 프롬프트, 채점 루브릭, 문제 생성 프롬프트
content/problems/    기본 문제 은행 (JSON 12문항)
data/                로컬 데이터: 설정·API 키, 응시 기록, 생성 문제 (git 제외)
```

새 문제를 직접 추가하려면 `content/problems/`에 기존 파일과 같은 형식의 JSON을 넣으면 됩니다.
